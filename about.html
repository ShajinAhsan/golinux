About GoLinux

A CLI-only Debian machine, emulated entirely in your browser.

What this is

GoLinux boots a 32-bit Debian 12 (bookworm) system inside your browser using v86, an x86 emulator written in WebAssembly. There is no server process: the machine runs on your device. The terminal is xterm.js.

Networking is disabled. Your files live in this browser's storage and are never uploaded. They survive reloads and closed tabs; clearing site data or using Reset removes them.

Guest operating system

Debian GNU/Linux 12 (bookworm), i386
Debian is free software; most components are under the GNU GPL, LGPL, and other free licenses. The exact terms for each package are in /usr/share/doc/<package>/copyright inside the machine.
debian.org · licensing · social contract

Because most of Debian is GPL-licensed, the corresponding source must be available. Every binary in this machine comes from Debian's archives:

  • sources.debian.org — browse the source of any installed package
  • deb.debian.org/debian/pool/main/ — the source and binary pools

To read the exact terms for a package inside the machine, run cat /usr/share/doc/<package>/copyright.
